\subsection{Collaborative Process}

The project was developed through the following collaborative process:

\begin{enumerate}
    \item \textbf{Planning Phase}: All members reviewed the project description and defined the system architecture together.
    
    \item \textbf{Design Phase}: Group discussion on security goals, labeling scheme, and Volpano method application.
    
    \item \textbf{Implementation Phase}: Section-wise drafting with peer review from other members.
    
    \item \textbf{Review Phase}: Cross-checking for consistency, completeness, and technical accuracy across all sections.
    
    \item \textbf{Finalization Phase}: Final compilation, formatting, and quality assurance.
\end{enumerate}

\subsection{Key Decisions}

\begin{itemize}
    \item \textbf{Choice of Volpano Method}: Selected as the second listed method in the project description, providing a type-system-based approach distinct from Denning's label-based method.
    
    \item \textbf{Three-Level Label Hierarchy}: Implemented private, friends, and public labels mapped to High, Medium, and Low security types respectively.
    
    \item \textbf{Hospital Scenario Application}: Used medical data hosting as the motivating example throughout the report to illustrate practical security requirements.
    
    \item \textbf{Comprehensive API Specification}: Defined both data operations and program execution commands to cover all system functionality.
    
    \item \textbf{Explicit Declassification Policy}: Included approved transformations (anonymization, aggregation, differential privacy) to enable practical data sharing.
\end{itemize}

\end{itemize}
