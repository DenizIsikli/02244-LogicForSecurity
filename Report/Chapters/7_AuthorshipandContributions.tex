\section{Conclusion}

This report presents a security argument that is explicit about assumptions, mechanisms, and limits. The Volpano type system provides static enforcement against unauthorized information flow, while API-level checks and channel assumptions provide the operational context needed for end-to-end reasoning.

For the hospital scenario, the main result is: private medical data is protected against both direct and control-flow-based leaks from untrusted programs, and any release to lower levels must go through a justified declassification step with policy constraints and auditability.

Key advantages of this design:
\begin{itemize}
    \item security properties are checked before execution,
    \item unsafe programs are rejected instead of partially executed,
    \item confidentiality claims are tied to explicit attacker/channel assumptions,
    \item declassification is controlled, parameterized, and accountable.
\end{itemize}

Residual risks outside the proven model (for example server compromise or covert hardware channels) are documented rather than ignored. This keeps the final claim precise: strong information-flow guarantees hold under the stated assumptions and enforcement path.
