\section{Declassification}

Volpano's type system prevents High→Low flows. However, controlled information release is sometimes legitimate.

\subsection{Approved Transformations}

\textbf{Anonymization}: Remove PII (names, IDs). Example: patient records → researcher dataset.

\textbf{Aggregation}: Compute statistics (mean, median, count). Example: individual measurements → population average.

\textbf{Differential Privacy}: Add calibrated noise to statistical queries. Provably hides individual contributions while providing useful aggregate information.

\subsection{Hospital Example}

\textbf{Scenario}: Anonymize medical records for research study.

\begin{enumerate}
    \item Researchers request: anonymize patient\_records
    \item Server runs approved anonymization program
    \item Type check: declassify(High) → Low (marked as trusted transformation)
    \item Output stored with label: public (Low)
    \item Researchers access anonymized dataset
\end{enumerate}

\textbf{Guarantee}: Individual patient data remains private. Only approved aggregate or anonymized data becomes public.
