\section{Volpano Type System Analysis}

\subsection{Type Lattice and Ordering}

The Volpano method assigns security types to variables. The type lattice is:
\begin{equation}
\textbf{Low} \sqsubseteq \textbf{Medium} \sqsubseteq \textbf{High}
\end{equation}

The ordering relation represents permissible information flow: $\tau_1 \sqsubseteq \tau_2$ means that information of type $\tau_1$ can flow to type $\tau_2$. The join operation is:
\begin{align}
\textbf{Low} \sqcup \textbf{Low} &= \textbf{Low} \\
\textbf{Low} \sqcup \textbf{Medium} &= \textbf{Medium} \\
\textbf{Low} \sqcup \textbf{High} &= \textbf{High}
\end{align}

\subsection{Type Inference Rules}

\textbf{Declaration}: Variables receive declared types: $\vdash x : \tau$ where $\tau \in \{\textbf{Low}, \textbf{Medium}, \textbf{High}\}$

\textbf{Constants}: Literals are type Low: $\vdash c : \textbf{Low}$

\textbf{Expressions}: Binary operations combine types via join:
\begin{equation}
\frac{\vdash e_1 : \tau_1 \quad \vdash e_2 : \tau_2}{\vdash e_1 \oplus e_2 : \tau_1 \sqcup \tau_2}
\end{equation}

\textbf{Assignments}: The type of the expression must be at most the type of the variable:
\begin{equation}
\frac{\vdash e : \tau_e \quad \tau_e \sqsubseteq \tau_x}{\vdash x := e}
\end{equation}

This prevents High-to-Low flows: if $\tau_x = \textbf{Low}$ and $\tau_e = \textbf{High}$, then $\textbf{High} \not\sqsubseteq \textbf{Low}$, so the assignment is a type error.

\subsection{Implicit Flow Analysis}

Control structures create implicit information flows. The Volpano method tracks a \textbf{program counter (pc)} level:

\textbf{If Statement}: The condition's type becomes the pc level within the guarded block:
\begin{equation}
\frac{\vdash b : \tau_b \quad \text{pc} := \tau_b \quad \vdash S_1, S_2}{\vdash \textbf{if } b \textbf{ then } S_1 \textbf{ else } S_2}
\end{equation}

Any assignment within the if block must satisfy: $\text{pc} \sqcup \tau_e \sqsubseteq \tau_x$.

\textbf{Example}: If a condition depends on a High variable (secret), then any assignment in the if block must go to a High variable, otherwise the assignment leaks information about the condition.

\begin{verbatim}
if (secret : High) then          // pc = High
    public_output : Low := 1     // ERROR: High ⊔ Low ⊑ Low? No!
\end{verbatim}

The type checker rejects this because High $\not\sqsubseteq$ Low.

\subsection{Application to Data Hosting}

\textbf{Data labels map to types}:
\begin{itemize}
    \item private → High: Cannot assign to Low variables
    \item friends → Medium: Can assign to Medium or High, but not Low
    \item public → Low: Can assign to any variable
\end{itemize}

\textbf{Program execution}: When a program $P$ runs on inputs $\vec{x}$ with types $\vec{\tau}$, the Volpano type checker verifies that the program body satisfies all type constraints. If type checking passes, the output type $\tau_{\text{out}}$ is computed. Programs are rejected at type-check time if they would leak information.
