\subsection{Supplementary Label-Check Pseudocode}

The server uses the following helper checks as part of command validation.

\begin{verbatim}
canRead(principal p, confLabel C):
  for each policy (owner o : readers R) in C:
    require p in closureActsFor(R)
  return true

canWrite(principal p, integLabel I):
  for each policy (owner o <- writers W) in I:
    require p in closureActsFor(W)
  return true

canFlow(label L1=(C1,I1), label L2=(C2,I2)):
  return confFlow(C1,C2) and integFlow(I1,I2)
\end{verbatim}

These checks are referenced in Chapters 4--6 when arguing command safety.
