\subsection{Volpano Type System Reference}

\subsubsection{Type Lattice}

\begin{equation}
\text{Security types: } \{\textbf{Low}, \textbf{Medium}, \textbf{High}\}
\end{equation}

\begin{equation}
\text{Ordering: } \textbf{Low} \sqsubseteq \textbf{Medium} \sqsubseteq \textbf{High}
\end{equation}

\subsubsection{Key Type Checking Rules}

\textbf{Assignment Rule}:
\begin{equation}
\frac{\vdash e : \tau_e \quad \tau_e \sqsubseteq \tau_x}{\vdash x := e}
\end{equation}

Prevents High→Low flows.

\textbf{Control Flow Rule}:
\begin{equation}
\frac{\vdash b : \tau_b \quad \tau_b = \text{pc} \quad (\text{pc} \sqcup \tau_e) \sqsubseteq \tau_x}{\text{Assignment in guarded block safe}}
\end{equation}

Prevents implicit flows through control structures.



\begin{align}
\textbf{Low} \sqcup \textbf{Low} &= \textbf{Low} \\
\textbf{Low} \sqcup \textbf{Medium} &= \textbf{Medium} \\
\textbf{Low} \sqcup \textbf{High} &= \textbf{High} \\
\textbf{Medium} \sqcup \textbf{Medium} &= \textbf{Medium} \\
\textbf{Medium} \sqcup \textbf{High} &= \textbf{High} \\
\textbf{High} \sqcup \textbf{High} &= \textbf{High}
\end{align}

\subsubsection{Type Checking Rules}

\textbf{Expression Rules}:

\begin{equation}
\frac{}{\vdash n : \textbf{Low}} \quad \text{(Constant Rule)}
\end{equation}

\begin{equation}
\frac{\vdash x : \tau}{\vdash x : \tau} \quad \text{(Variable Rule)}
\end{equation}

\begin{equation}
\frac{\vdash e_1 : \tau_1 \quad \vdash e_2 : \tau_2}{\vdash e_1 \oplus e_2 : \tau_1 \sqcup \tau_2} \quad \text{(Binary Op Rule)}
\end{equation}

\textbf{Statement Rules}:

\begin{equation}
\frac{\vdash e : \tau_e \quad \tau_e \sqsubseteq \tau_x}{\vdash x := e} \quad \text{(Assignment Rule)}
\end{equation}

\begin{equation}
\frac{\vdash b : \tau_b \quad \tau_b = \text{pc} \quad \vdash S}{\vdash \textbf{if } b \textbf{ then } S} \quad \text{(If Rule)}
\end{equation}

\begin{equation}
\frac{\vdash b : \tau_b \quad \tau_b = \text{pc} \quad \vdash S}{\vdash \textbf{while } b \textbf{ do } S} \quad \text{(While Rule)}
\end{equation}

\subsection{Example Programs with Type Checking}

\subsubsection{Example A: Safe Image Processing}

\begin{verbatim}
Program: image_filter
Input: medical_image : High

Type declarations:
  medical_image : High
  pixel_array : High
  filtered_array : High
  output : High

Code:
  pixel_array := read_pixels(medical_image)
  filtered_array := apply_filter(pixel_array)
  output := create_image(filtered_array)
  return output

Type Check:
  Line 1: High ⊑ High ✓
  Line 2: High → High (filter preserves type) ✓
  Line 3: High ⊑ High ✓
  Result: Type check PASSES. Output type = High.
  
Access: Only owner can access output.
\end{verbatim}

\subsubsection{Example B: Explicit Leak Detection}

\begin{verbatim}
Program: data_exfiltration (MALICIOUS)
Input: secret : High, public_output : Low

Type declarations:
  secret : High
  public_output : Low
  extracted : ?

Code:
  extracted := secret + 1
  public_output := extracted

Type Check:
  Line 1: High + Low = High ⊔ Low = High
           Assignment to extracted: High ⊑ type(extracted)
           Type of extracted inferred as High ✓
  Line 2: High ⊑ Low? 
           NO! (High ⊈ Low)
           TYPE ERROR: Explicit leak detected
           
Result: Type check FAILS. Program rejected.
\end{verbatim}

\subsubsection{Example C: Implicit Leak Detection}

\begin{verbatim}
Program: side_channel_leak (MALICIOUS)
Input: secret : High, public_counter : Low

Type declarations:
  secret : High
  public_counter : Low
  i : Low

Code:
  i := 0
  while (secret > 0):
    public_counter := public_counter + 1
    secret := secret - 1
  return public_counter

Type Check:
  Condition: secret : High, so pc := High
  Loop body assignment: public_counter : Low
    Effective type: pc ⊔ type(rhs) = High ⊔ Low = High
    Constraint: High ⊑ Low?
    NO! (High ⊈ Low)
    TYPE ERROR: Implicit leak via loop timing
    
Result: Type check FAILS. Program rejected.
\end{verbatim}

\subsubsection{Example D: Safe Aggregation (Declassification)}

\begin{verbatim}
Program: compute_statistics (APPROVED DECLASSIFIER)
Input: patient_data : High (array of records)

Type declarations:
  patient_data : High
  count : Low (safe aggregate)
  average_age : Low (safe aggregate)
  statistics_output : Low

Code:
  count := COUNT(patient_data)
  average_age := AVERAGE(patient_data.age)
  
  // Declassification: aggregates are safe to release
  statistics_output := create_summary({
    total_patients: count,
    avg_age: average_age
  })
  
Type Check:
  - COUNT() is declared as: (High -> Low) with declassification
  - Type system recognizes declassification
  - Output type: Low (statistics safe for public)
  
Result: Type check PASSES. Output type = Low.

Security Guarantee: 
  Individual data is High (protected).
  Aggregates are Low (safe for research).
  No information about individual patients leaks.
\end{verbatim}

\subsection{Type System Formalization}

For completeness, the Volpano type system can be formalized as:

\begin{equation}
\Gamma \vdash S : \text{OK}
\end{equation}

where:
\begin{itemize}
    \item $\Gamma$ is a type environment (variable → type mapping)
    \item $S$ is a statement/program
    \item \textbf{OK} indicates type checking passed
\end{itemize}

The type checker constructs a set of constraints and verifies that they satisfy the security lattice ordering. If all constraints are satisfiable (no High $\to$ Low flow), the program is secure.

\subsection{Performance Characteristics}

\begin{itemize}
    \item \textbf{Type Checking}: Polynomial time (typically linear to quadratic in program size)
    \item \textbf{Runtime Execution}: No overhead (security checks are static)
    \item \textbf{Scalability}: Suitable for large programs and systems
\end{itemize}
