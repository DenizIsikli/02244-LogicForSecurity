\section{Introduction}

This report analyzes a data hosting server using the \textbf{Volpano type system method} for secure information flow. The system supports three features: user-controlled security labeling, policy-based data sharing, and untrusted program execution. We provide formal guarantees that confidential data cannot leak to unauthorized users through either explicit assignments or implicit control-flow channels.

\subsection{System Overview}

The server hosts medical data (hospital scenario) with three confidentiality levels: \texttt{private} (High, owner-only), \texttt{friends} (Medium, designated friends), and \texttt{public} (Low, all users). Users can execute programs on data, but these programs are untrusted. The Volpano method ensures that even malicious programs cannot violate information flow policies through static type checking performed before execution.

\subsection{Volpano Type System Method}

The Volpano approach provides a \textbf{sound type system} for enforcing secure information flow:

\begin{itemize}
    \item \textbf{Type ordering}: Low $\sqsubseteq$ Medium $\sqsubseteq$ High, where High represents confidential data.
    \item \textbf{Type rules}: Enforce that High information cannot flow to Low outputs (explicit leaks) and control dependencies don't leak information (implicit flows via program counter).
    \item \textbf{Soundness}: Type checking guarantees no unauthorized information flows.
    \item \textbf{Static verification}: Security is checked at design time, eliminating runtime overhead.
\end{itemize}

\textbf{Key distinction from Denning's approach}: Volpano uses type inference to automatically determine security types, whereas Denning's label-based method requires manual label assignment and constraint solving.
